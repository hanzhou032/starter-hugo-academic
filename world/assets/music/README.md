# Islands of Discovery

An original composition and sampled orchestral performance made for this
portfolio, with newly written music inspired by a broad fantasy-orchestral
mood. No TI8 or TI10 recordings, melodies, streams, or player APIs are used.

Instruments: VSCO 2 Community Edition, CC0-1.0, by Versilian Studios /
Sam Gossner and contributors including Ivy Audio.

- https://github.com/sgossner/VSCO-2-CE
- https://vis.versilstudios.com/vsco-community.html

The CC0 license is included alongside this file. The original note-event score,
reference MIDI, pinned sample manifest and renderer are in `scripts/music/`
in the source repository.
